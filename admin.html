Token för att spara direkt till GitHub ingen token
Skapa en fine-grained token under Settings → Developer settings. Ge den bara det här repot och bara Contents: Read and write. Sätt ett utgångsdatum.
Läcker en sådan token kan den ändra den här sidan och ingenting annat. Alla *.github.io-sidor delar samma lagringsutrymme i webbläsaren, så välj Bara den här fliken om du sitter vid en dator du inte äger.
